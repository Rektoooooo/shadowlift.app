# ShadowLift Website

Official website for [ShadowLift](https://shadowlift.app) - The ultimate fitness tracking app for serious lifters.

## Tech Stack

- React 18
- Vite
- React Router
- GSAP (animations)
- OGL (WebGL effects)

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

The site is deployed to GitHub Pages:

```bash
npm run deploy
```
